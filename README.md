# 💳 Credit Scoring Model

A machine learning-based credit scoring application that predicts loan risk based on customer financial and credit-related information.
This project was developed as part of a **CodeAlpha Machine Learning Internship** and includes an interactive web application built with **Streamlit**.

## 📌 Project Overview

The Credit Scoring Model uses customer financial and credit information to predict the loan status.
The model analyzes factors such as,

* Customer age
* Income
* Employment length
* Home ownership
* Loan purpose
* Loan grade
* Loan amount
* Interest rate
* Loan percentage of income
* Previous default history
* Credit history length

The prediction is generated using a **Random Forest Classifier**.

## 🎯 Objective

The main objective of this project is to demonstrate how machine learning can be used to analyze credit-related information and provide a prediction of loan risk.

## 🧠 Machine Learning Model

The project uses a **Random Forest Classifier** from Scikit-learn.

### 🔄 Data Processing

The dataset is processed before training the model,

1. The credit dataset is loaded using Pandas.
2. The previous default history field is converted into numerical values.
3. Categorical features are converted using one-hot encoding.
4. The dataset is divided into training and testing data.
5. A Random Forest classification model is trained using the training data.
6. The trained model predicts the loan status for new customer information.

### ⚙️ Model Configuration

The Random Forest model uses,

* `n_estimators = 100`
* `max_depth = 10`
* `random_state = 42`

The training process also includes class balancing in the command-line model.

## 📊 Dataset

The project uses a CSV dataset named,

`credit_data.csv`

The dataset contains **32,581 records and 12 attributes**.

### 📋 Dataset Attributes

| Attribute                    | Description                           |
| ---------------------------- | ------------------------------------- |
| `person_age`                 | Customer age                          |
| `person_income`              | Customer income                       |
| `person_home_ownership`      | Home ownership type                   |
| `person_emp_length`          | Employment length                     |
| `loan_intent`                | Purpose of the loan                   |
| `loan_grade`                 | Loan grade                            |
| `loan_amnt`                  | Loan amount                           |
| `loan_int_rate`              | Loan interest rate                    |
| `loan_status`                | Target variable                       |
| `loan_percent_income`        | Loan amount as a percentage of income |
| `cb_person_default_on_file`  | Previous default history              |
| `cb_person_cred_hist_length` | Credit history length                 |

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
```

### 2. Open the Project Folder

```bash
cd Credit_Scoring_Model
```

### 3. Install the Required Libraries

```bash
pip install -r requirements.txt
```

## ▶️ Run the Streamlit Application

From the folder containing `app.py` and the `data` folder, run:

```bash
streamlit run app.py
```

The application will open in your web browser.

## 💻 Run the Python Model

The project also contains a command-line version in `main.py`, run:

```bash
python main.py
```

This version loads the dataset, trains the Random Forest model, evaluates the model using accuracy, and allows customer information to be entered through the terminal.
